Detailed Description

A QTreeView that clears its selection, and emits emptyClicked(), when the user clicks empty space or an already-selected item.

The press records whether the row under the pointer was selected, the release handles selection immediately and arms a single-shot timer for the platform's double-click interval, and only when no double-click arrives in that time does deselect() clear the selection. Opening an entry by double-click therefore always wins over deselecting it.
