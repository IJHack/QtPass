Detailed Description

Puts secrets on the system clipboard and takes them off again.

Remembers what it copied so the autoclear timer (and the quit handler) only remove that text, never something the user copied in the meantime. Settings (selection vs. clipboard, autoclear on/off, delay) are read from QtPassSettings; call setAutoclearTimer() after they change. Status text for the main window's status bar is emitted, not shown, so this class has no UI dependency and is unit-testable.

◆ copyIfAlways()

void ClipboardManager::copyIfAlways ( const QString & text,
const QString & p_output = QString() )

Handle clipboard copying for a shown entry.

In "always copy" mode (and only then) this copies text via copyText(), which also arms the autoclear timer and records the clipboard contents. In other modes it does nothing, leaving any pending autoclear tracking intact.

Parameters
textPassword (or value) of the entry being shown.
p_outputFull decrypted output; copying is skipped when it is empty.

◆ trackCopied

void ClipboardManager::trackCopied ( const QString & text)
slot

Track text that got onto the clipboard some other way.

For a copy QtPass did not make through copyText(): text selected and copied from a widget showing a secret (Ctrl+C, the context menu, a drag, or the X11 primary selection that a mouse selection fills). The text is cleared with the rest when the autoclear timer runs; what copyText() tracks stays tracked too.

Parameters
textThe copied text; nothing happens when it is empty.
