Detailed Description

RFC 4648 base32 codec, used for TOTP shared secrets.

Ported from KeePassXC (src/core/Base32.cpp). decode() is deliberately strict: the input length must be a multiple of 8 and every character must be in the base32 alphabet, so whitespace is an error rather than something to skip. Secrets that come from a human (or from a QR code label) therefore go through sanitizeInput() first, making the canonical entry point:

const QByteArray secret =
Base32::decode(Base32::sanitizeInput(text.toLatin1()));

auto Base32::sanitizeInput ( const QByteArray & encodedData) -> QByteArray
staticnodiscard

Make human-entered base32 text decodable.

Drops every character outside "A-Za-z2-7" (so the spaces and dashes used to group a printed secret are tolerated), maps the digits that are ambiguous in the base32 alphabet (0 to O, 1 to L, 8 to B), then pads the result with addPadding().

Parameters
encodedDataRaw user input.
Returns
Sanitized, padded base32 text.
