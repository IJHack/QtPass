Detailed Description

QPushButton that toggles visibility of an associated QLineEdit.

The button is icon-only and bound to one QLineEdit for its lifetime. Each click flips that line edit between QLineEdit::Password and QLineEdit::Normal echo mode and swaps the icon, tooltip and accessible name between "Show password" and "Hide password" to match. It is driven entirely by its own QPushButton::clicked signal; the owner only has to create it next to the line edit (PasswordDisplayPanel does this for the masked password row of a decrypted entry).
