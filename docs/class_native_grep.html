Detailed Description

Full-text search over a password store without pass grep: every .gpg file is decrypted with gpg on a worker thread and its lines matched against a QRegularExpression. Only the newest search may report; a search started while another runs asks that one to stop and supersedes it.

Whether a line in a result is the marker for "more matches in this entry" rather than a match.

A match is a trimmed, non-empty line, so an empty one can only be the marker, which matchFile() and scanStore() put last. Not a match: not counted, not content to hide.

staticconstexpr

Most matching lines taken from one entry.

A compressed entry can expand into millions of lines within the plaintext limit, each a result and a row in the results list; past this many, the entry gets one line saying there are more.

◆ kMaxPreviewLength

qsizetype NativeGrep::kMaxPreviewLength = 200
staticconstexpr

Longest preview of a matching line, in UTF-16 code units.

A result shows where the pattern matched, not the line; a single line can be most of an entry's 64 MiB plaintext, and 10000 such copies would not fit in memory. A longer line is shown as a window of this many code units around the match (up to two more, one per edge, to keep a surrogate pair whole), "…" where the line goes on. A sequence of several code points (a ZWJ emoji, a flag) can still be cut between them.
