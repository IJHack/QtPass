Detailed Description

One named password store: where it is, how its .gpg-id is signed and, optionally, its own Git switches.

The Git flags are tri-state on disk ("" / "true" / "false"): unset means "follow the global setting", which is what every profile written before 1.8.0 has. Keys are stored under profile/<name>/ and are unchanged from the QHash-of-QHash days.
