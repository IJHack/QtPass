Detailed Description

The name of a key: value field in PasswordDialog, editable in place: double-click or the context menu renames it, the context menu can also remove the field (#132).

The label only reports what the user asked for; PasswordDialog owns the line edit the field belongs to and decides whether a new name is usable.
