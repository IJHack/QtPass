Detailed Description

What QtPass knows about one kind of subprocess: what to call it and whether its output may carry a secret.

One table (processInfo()) answers both questions, so a process kind cannot be labelled in the output panel while being classified as harmless somewhere else. A new PROCESS value has to be added to it or the build fails, which is how the classification gets made rather than forgotten.
