Detailed Description

QPushButton that stores a text payload and emits it when activated.

The button does not touch the clipboard itself. On activation it briefly swaps to a "done" icon (reverted after 500 ms) and re-emits clicked(const QString&) with the stored text; the receiver (normally ClipboardManager via PasswordDisplayPanel) performs the copy and the autoclear bookkeeping.
