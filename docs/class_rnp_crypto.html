Detailed Description

OpenPGP encryption and decryption in-process, through RNP.

A spike towards a backend that needs no gpg, git or pass binary (#2005): the same work ImitatePass hands to gpg, done by the RNP library (the OpenPGP code Thunderbird uses). Keys live in this object's own keyring, filled from armored exports (gpg –export / –export-secret-keys); it never reads or writes ~/.gnupg. Built only with CONFIG+=rnp.

Output is binary OpenPGP, as pass and QtPass write .gpg files. Every call reports failure through its return value and a human-readable error.

Security trade-off (SECURITY.md, "In-process OpenPGP"): with gpg, QtPass never holds a secret key; gpg-agent does, or a smartcard. Here the secret key is imported into this process and, while a message is decrypted, the unlocked key and the passphrase are in its memory. Imported keys keep their own passphrase protection; no smartcard support. A mode built on this must be chosen deliberately, never used as a silent fallback for a missing gpg.

auto RnpCrypto::decrypt ( const QByteArray & ciphertext,
QString * error = nullptr,
bool * ok = nullptr ) -> QByteArray

Decrypts an OpenPGP message with any secret key in the keyring.

Only an integrity-protected message is accepted (SEIPD with MDC, or AEAD such as the OCB packets GnuPG 2.4 writes): one without (CFB with no MDC, the EFAIL kind) is refused, as GnuPG has since 2.2.8. A plaintext over the limit (setMaxPlaintextBytes()) fails too.

Parameters
ciphertextBinary or armored OpenPGP message.
errorSet to the reason when decryption fails.
okSet to whether decryption succeeded, since an entry can be empty.
Returns
The plaintext, empty on failure.

Encrypts plaintext to every recipient, as one message.

Parameters
plaintextThe entry's content.
recipientsAs a .gpg-id lists them, in the forms gpg -r takes: a fingerprint (40 or 64 hex digits, blanks allowed), a long or short (8 hex digits) key ID with or without 0x, an e-mail address (the key with a user ID of that address, any case; stricter than gpg's substring search; a user ID with no address in angle brackets must then be just the address, so "alice@example.org (work)" is not found by its address), or a whole user ID or part of one. Revoked user IDs, and ones without a valid self-signature, name nothing. Each must name exactly one key that can encrypt (not expired or revoked, with a usable encryption key); an empty recipient is an error.
errorSet to the reason when encryption fails, naming the first recipient that has no usable key or names more than one.
Returns
The binary OpenPGP message, empty on failure.

◆ protectKey()

auto RnpCrypto::protectKey ( const QString & fingerprint,
const QString & passphrase,
QString * error = nullptr ) -> bool

Protects the secret parts of a key with passphrase.

For a key imported without protection: saveKeyring() keeps secret keys on disk only protected by their own passphrase. Only the parts not yet protected get passphrase, so a key left half protected can be finished; the others keep theirs (no passphrase is changed here). A key all of whose secret parts are protected already is an error.

Parameters
fingerprintThe primary key's fingerprint.
passphraseThe passphrase; not empty.
errorSet to the reason when not every part ended up protected.
Returns
Whether every secret part of the key here is now protected.

◆ saveKeyring()

auto RnpCrypto::saveKeyring ( const QString & dir,
bool allowUnprotected = false,
QString * error = nullptr ) const -> bool

Writes the keyring to dir: keyring.gpg, public and secret keys in one file (OpenPGP keys, as GnuPG 1 kept them), owner-only and replaced whole, so a reader sees the old keyring or the new one.

Secret keys are written as they are held: protected by their own passphrase, never decrypted for this. A secret key without protection is refused (nothing is written) unless allowUnprotected, the user's explicit consent; protectKey() first is the other way.

Parameters
dirThe keyring folder, created owner-only if missing; QtPass's own, never ~/.gnupg.
allowUnprotectedWrite unprotected secret keys as well.
errorSet to the reason when nothing was written, naming the first unprotected key.
Returns
Whether the keyring was written; false, and nothing written, also when it would be larger than loadKeyring() reads.

Checks a detached signature over data, as QtPass reads gpg's VALIDSIG.

The first signature that verifies decides. A signature by a key that is now revoked (or whose primary is) counts for nothing, as with GnuPG in GpgIdSigner; one by a key that has since expired still counts, as gpg calls it a good signature.

◆ kMaxPlaintextBytes

qint64 RnpCrypto::kMaxPlaintextBytes = 64LL * 1024 * 1024
staticconstexpr

Most bytes of plaintext decrypt() produces by default.

An OpenPGP message is compressed, so a small entry in a shared store can decompress to gigabytes; decrypt() fails at this many instead of filling memory. The same limit QtPass gives gpg (–max-output).
