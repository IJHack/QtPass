Detailed Description

Live one-time password display: code, copy button and countdown.

Rendered by PasswordDisplayPanel as the value side of the "OTP Code" row. It is a widget rather than a set of loose children so that its refresh timer is a child of the thing it updates: PasswordDisplayPanel::clear() deletes the row's widgets, which destroys this widget and therefore the timer. A timer owned by the panel instead could fire after its label had been deleted.

The code is recomputed from the wall clock on every tick rather than from an internal counter, so a machine that suspends across a period boundary self-corrects on the first tick after resume.
