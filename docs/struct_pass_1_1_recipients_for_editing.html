enum class Pass::RecipientsForEditing::State
strong

How the list on disk stood up.

Enumerator
Unsigned 

No signing key: the list as it is.

Verified 

Signature and generation and folder all accepted.

VerifiedRollback 

Signed, authentic and bound to this folder, but older than a generation this device has accepted: preselected for the recovery, flagged for review.

Rejected 

Not to be used: signature invalid, written for another folder or for no folder in particular while a generation was accepted here, malformed header, or no freshness record to judge by.
