Detailed Description

Dialog for selecting GPG recipients for password encryption.

UsersDialog allows users to select which GPG keys to encrypt passwords to. It displays available keys, supports filtering, and shows key expiration status.

◆ setInitOnAccept()

void UsersDialog::setInitOnAccept ( bool initOnAccept)
inline

Choose whether OK runs Pass::Init on the folder.

On by default. Off, the dialog only collects the selection; the caller reads selectedUsers() and initialises the folder itself (new profiles, which must not go through the backend of the active store).

Parameters
initOnAcceptfalse to skip Pass::Init.
