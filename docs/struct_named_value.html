QString NamedValue::originalLine

The field's verbatim source line, colon and spacing intact.

The edit dialog writes an untouched field back from this, so saving does not reformat key:value to key: value, trim the value, or drop a field whose value is empty. Empty when the field has no source line (a template field the file did not fill).
