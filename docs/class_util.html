Expand a leading current-user tilde in a path.

Environment variables set outside a shell (systemd units, .desktop entries, quoted assignments) keep a literal "~", which no filesystem call resolves. "~" and "~/..." become the home directory; "~user" forms and everything else are returned unchanged.

Locate an executable in an explicit list of directories.

Only regular, executable files match; a directory named like the binary is skipped. Empty entries are ignored (they never resolve to the current working directory) and an empty list finds nothing. Only bare names are searched: an absolute path, or a name containing a directory separator, finds nothing rather than escaping searchPaths.

◆ isLaunchableWebUrl()

auto Util::isLaunchableWebUrl ( const QString & value) -> bool
static

Check whether a value is a safe, launchable web URL.

Stricter than protocolRegex(): intended to gate an "open in browser" action, where launching a non-web scheme would be a security risk. Returns true only when the trimmed value:

  • contains no control characters (CR, LF, NUL),
  • parses to a valid QUrl,
  • has scheme exactly "http" or "https" (case-insensitive),
  • has a non-empty host,
  • carries no embedded userinfo (user:password@host).

Deliberately rejects file://, javascript:, data:, ftp/ssh/webdav and scheme-less inputs (e.g. "www.example.com").

Parameters
valueCandidate URL string (typically a password-file field).
Returns
true if the value is a launchable http(s) URL, false otherwise.

Turn plain text into HTML with clickable links for safe web URLs.

The single rule for every place a value is rendered into an <a href>: the text is HTML-escaped, and only the protocolRegex() matches that also pass isLaunchableWebUrl() become anchors. Everything else (ssh://, ftp://, URLs carrying user:pass@ credentials, ...) stays escaped plain text, so a click can never hand a non-web scheme or a secret to the OS URL handler via QTextBrowser::setOpenExternalLinks().

linkedOptional out parameter, set to true when at least one anchor was produced.
Returns

◆ regularFilesUnder()

auto Util::regularFilesUnder ( const QString & dir,
const QStringList & nameFilters,
QStringList * skipped = nullptr,
bool hiddenFiles = false ) -> QStringList
static

Regular files under dir whose name matches one of nameFilters, found by walking only real directories.

Symbolic links and NTFS junctions are never entered and never listed: either can point outside the tree, and QDirIterator's own recursion treats a junction as an ordinary directory (Qt marks it JunctionType, not LinkType, so QDir::NoSymLinks does not see it). Hidden directories (.git, a sync tool's version folder) are not entered either, as with QDirIterator without QDir::Hidden.

dir itself is followed whatever it is: the configured store root is commonly a symlink (~/.password-store to a synced folder), and it is the user's choice, not something found inside the store. A caller that gets its folder from the store tree decides with isLinkedFolder() first.

The walk is a listing, not a lock: what is a regular file when listed can be replaced before it is opened. That is the store's trust boundary (SECURITY.md), not something a walk can close.

Parameters
dirDirectory to walk.
nameFiltersWildcards, as for QDir::setNameFilters().
skippedReceives what was left out although it is in the way: every linked directory, and every link or special file (FIFO, socket, device) whose name matches nameFilters. Null to not care.
hiddenFilesList hidden files too (.gpg-id); hidden directories stay closed regardless.
Returns
Absolute paths, sorted by name within each directory, a directory's files before its subdirectories.
