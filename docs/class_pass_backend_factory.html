Detailed Description

Owns the Pass backend lifecycle (RealPass vs ImitatePass).

Extracted from QtPassSettings, which conflated settings storage with deciding and caching which password-store backend is active. The factory lazily constructs the two concrete backends, hands out the active one based on the configured mode, and exposes invalidate() so a settings change can force the active backend to be re-selected on next use.
