Detailed Description

QPushButton that presents a text payload as a QR code action.

The button is icon-only (theme icon qrcode) and carries the text of the field it sits next to. It does not render the QR code itself: on activation it re-emits clicked(const QString&) with the stored text. The owning PasswordDisplayPanel passes that on, and QtPass::showTextAsQRCode() opens the QR dialog.
