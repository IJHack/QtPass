Detailed Description

Tracks a sequence of processes that should be treated as one atomic operation.

ImitatePass queues several processes for one operation (gpg, then git add, then git commit for an insert) and wants to report the operation once, when the last of them ends. Between transactionStart() and transactionEnd() it calls transactionAdd() for each process it queues; transactionEnd() names the result to report. As processes finish, transactionIsOver() answers with that result for the last one of a transaction and with Enums::INVALID for every earlier one. Transactions may nest; only the outermost one counts.
