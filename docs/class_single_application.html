Detailed Description

QApplication subclass enforcing single-instance behavior via IPC.

Detects whether another instance with the same unique key is running and enables forwarding messages (e.g., command-line arguments) to it.

Construct a SingleApplication with a unique instance key.

Attaches to the shared-memory segment named uniqueKey. If an instance answers on the local socket this becomes a secondary and isRunning() turns true; if the segment is stale (left behind by a crash) or absent, this instance claims it and starts listening.

void SingleApplication::becomePrimary ( )

Claim the segment and listen; no-op when another instance holds it.

When the segment is already taken the other launcher is probed a few times (see takeoverProbes) and, if it answers, this becomes a secondary. Otherwise isRunning() stays false and the caller runs without IPC rather than not at all.

◆ receiveMessage

void SingleApplication::receiveMessage ( )
slot

Slot for QLocalServer::newConnection: accept every pending connection and emit messageAvailable() with what it sent.

Each accepted socket is read asynchronously so a peer that connects without sending anything cannot stall the GUI thread; the message is delivered once the peer disconnects and the socket is then deleted.

◆ sendMessage()

auto SingleApplication::sendMessage ( const QString & message) -> bool

Send a message to the running instance.

When delivery fails the peer is taken to have exited since the constructor probed it: this instance releases its segment and, if it can, becomes the listening instance itself, so isRunning() turns false and the window the caller opens next is reachable by later launches.

Parameters
messageText to deliver (typically forwarded command-line args).
Returns
true if the message was successfully delivered.
