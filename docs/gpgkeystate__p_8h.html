UserInfo & current_user )

Replace the key ID of the key being built with its fingerprint.

Only when the fpr record's value is shaped like a fingerprint (40 or 64 hex digits) and ends in the key ID already there, so a subkey's fingerprint is never taken for the primary key's.

Parameters
propsThe colon-split fields of the record.
current_userThe key being built; its key ID may be replaced.

Start a key from a pub or sec record: key ID, the user ID the record may carry, validity, creation and expiry time.

An empty expiry field (gpg's "no expiry") leaves the date null. A record with fewer than ten fields changes nothing.

Parameters
propsThe colon-split fields of the record.

current_userThe key being built; filled in.
