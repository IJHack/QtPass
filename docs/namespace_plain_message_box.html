Detailed Description

Message boxes whose text is shown as the text it is.

QMessageBox's static helpers read their text as rich text when it looks like it (Qt::AutoText). A message quoting a name from the store would then be markup that other writers of a shared store control: a folder named <img src=" with dev/zero">.gpg beneath it has Qt read /dev/zero without end. These set Qt::PlainText before the text, for every message that quotes a path, a field or anything else from the store.
