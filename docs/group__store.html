Detailed Description

The password store as files on disk: the tree shown in the main window, path checks, and the content of an entry.

StoreTree and StoreModel present the store folder. PathValidator keeps operations inside it. FileContent parses a decrypted entry into password, template fields and the rest; Totp computes one-time codes from it.
