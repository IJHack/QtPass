Detailed Description

A QPlainTextEdit for decrypted entry text being edited: whatever is copied or cut out of it is marked as a secret and reported for autoclear.

As in SecretTextBrowser, every way text leaves the editor (Ctrl+C, Ctrl+X, the context menu, a drag, and the X11 primary selection a mouse selection fills) goes through createMimeDataFromSelection().
