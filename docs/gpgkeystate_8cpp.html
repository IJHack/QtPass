◆ parseGpgColonOutput()

auto parseGpgColonOutput ( const QString & output,
bool secret )

Parse a gpg colon listing into one UserInfo per key.

A pub or sec record starts a key; the first uid after it supplies the name when the key record carried none, and an fpr record whose value ends in the key ID replaces the key ID with the full fingerprint. Lines with fewer than ten fields are skipped.

Parameters
outputRaw output of gpg --with-colons --with-fingerprint.
secretTrue when output lists secret keys (--list-secret-keys); the keys are then marked as having a secret part.
Returns
The keys, in the order gpg listed them.

◆ primaryFingerprintOf()

auto primaryFingerprintOf ( const QString & output,
const QString & key )

The primary key fingerprint of the key that key names.

gpg accepts a signature by a subkey for its primary key, and verification here takes either fingerprint from VALIDSIG: a key written as a subkey's fingerprint, or as a key ID, signs as its primary key. Only the block that holds key is taken, whatever else gpg printed; when several do (a short ID, which collides easily), none is.

Parameters
outputRaw output from GPG –with-colons –with-fingerprint –with-subkey-fingerprint –list-keys.
keyA fingerprint (40 or 64 hex) or a key ID (8 or 16 hex), optionally with 0x; any case. A key ID is matched against the record's own key ID, so it works for v4 keys (the fingerprint's tail) and v5/v6 keys (its head) alike.
Returns
The primary fingerprint in upper case, or empty when no block, or more than one, in output holds key.
