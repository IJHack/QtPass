Detailed Description

Handles the system tray icon and menu.

A QObject parented to the main window: nothing here is a widget (the menu and the QSystemTrayIcon are children of this object), and the parent makes sure ~QSystemTrayIcon runs on quit, which is what removes the icon from the notification area on Windows.
