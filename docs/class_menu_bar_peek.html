Detailed Description

Shows a hidden menu bar while Alt is used, as browsers and file managers do.

Pressing Alt in the window shows the bar, so Alt+F and the other mnemonics open their menus. A lone tap leaves it up until Alt is tapped again, Escape is pressed, the window is clicked or loses focus; after a menu closes, or after an Alt shortcut that was not a menu, it goes again. The stored "Show menu bar" choice is never touched: checking it during a peek keeps the bar.
