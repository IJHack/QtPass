Detailed Description

Shows a hidden menu bar while Alt is used, as browsers and file managers do.

Pressing Alt in the window shows the bar, so Alt+F and the other mnemonics open their menus. A lone tap leaves it up until Alt is tapped again, Escape is pressed, the window is clicked or loses focus; after a menu closes, or after an Alt shortcut that was not a menu, it goes again. The stored "Show menu bar" choice is never touched: checking it during a peek keeps the bar.

◆ onKeyPress()

void MenuBarPeek::onKeyPress ( QObject * watched,
const QKeyEvent * event )
private

Handle a key press seen by the application filter.

A first, non-repeated Alt press inside the window shows the bar when it is hidden; any other key marks the press as "Alt plus something", and Escape during a peek hides the bar. A key event reaches the filter once for every widget it propagates to and again as auto-repeat; m_altDown makes the second sighting a no-op.

Parameters
watchedThe object the event was sent to.
eventThe key press.
