Detailed Description

Read and write password-store template configuration.

Extracted from Util. Owns the .templates INI-style file (named template sections with field lists) and the per-folder .default_template lookup used to pick a default template when adding a password.

◆ secretFieldsIn()

auto TemplateIO::secretFieldsIn ( const QString & templateText) -> QStringList
static

The field names a template marks as secret.

A line # secret: pin, cvv names them, separated by commas; "secret" may be written in any case. It is a comment line, so pass, QtPass 1.8 and the field list skip it. Names are trimmed and empty ones dropped; every other line is ignored. A marked field is hidden like the password (PasswordDisplayPanel), matched by its whole name in any case.

Parameters
templateTextThe text of a template: the store's .templates file or the template in the settings.
Returns
The marked names in the order they appear.
