Detailed Description

A QTextBrowser for decrypted entry text: whatever is copied out of it is marked as a secret and reported for autoclear.

Every way text leaves a QTextEdit (Ctrl+C, the context menu's Copy, a drag, and the X11 primary selection a mouse selection fills) goes through createMimeDataFromSelection(). Here that builds the same MIME data as ClipboardManager, with the platform hints that keep clipboard history and cloud clipboard out, and emits copied() so the text is cleared with the rest when the autoclear timer runs.
