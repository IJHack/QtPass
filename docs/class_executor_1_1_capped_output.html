Detailed Description

A stream of bytes held as its first and last kMaxStderrBytes / 2 bytes, with its gpg status records counted whole.

What is left out of the text is still counted: a caller that judges a run by its status records (RealPass counting END_ENCRYPTION against the entries pass re-encrypted) reads statusCounts(), not the capped text.

◆ statusCounts()

auto Executor::CappedOutput::statusCounts ( ) const -> QHash< QString, qint64 >
inlinenodiscard

How many complete lines of each gpg status keyword came by since the last take(), the left-out ones included.

A line counts when it starts with "[GNUPG:] "; its keyword is the word after that. Lines longer than kMaxStatusLineBytes, and keywords past the first kMaxStatusKeywords, are not counted: gpg's own status lines are short and few in kind.

Returns
Keyword to count.
